# Client Whitelist
#
# One pattern per line (case-insensitive), lines starting with # are comments.
# Two kinds of entries are supported in the same file:
#   utorrent     User-Agent substring (HTTP / WebSocket)
#   -ut          peer_id prefix (UDP / WebSocket, and HTTP announce)
#
# UDP has no User-Agent, so a whitelist used by UDP must contain at least one
# peer_id prefix starting with "-"; startup fails with a clear error otherwise.
#
# The client ban list still applies: a whitelisted client can also be banned.

# uTorrent
utorrent
-ut
