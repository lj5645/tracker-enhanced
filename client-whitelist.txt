# 客户端白名单
#
# 一行一个模式（不区分大小写），以 # 开头的行为注释。支持两种写法：
#   utorrent     User-Agent 子串，用于 HTTP / WebSocket
#   -ut          peer_id 前缀，用于 UDP / WebSocket（以及带 peer_id 的 HTTP announce）
#
# 同一个文件可以混用两种模式。UDP 没有 User-Agent，因此使用 UDP 时
# 必须至少包含一个以 "-" 开头的 peer_id 前缀，否则启动会报错。
#
# 注意: 只有当 [client_whitelist] mode = "on" 时才生效。
# 客户端封禁列表仍然生效，白名单不会覆盖它。

utorrent
-ut

transmission
-tr

qbittorrent
-qb

# Deluge
deluge
-de

# rTorrent
rtorrent
-rt

libtorrent
-lt

bittorrent
